# Java

Console programs I wrote while learning Java.

## Programs

| Program | Description |
|---------|-------------|
| [ContactBook](ContactBook/) | Add, search, update and delete contacts, saved to a file |
| [BankAccountSystem](BankAccountSystem/) | Interactive menu to view bank account details |
| [Banking](Banking/) | Basic banking program |
| [StudentManagementSystem](StudentManagementSystem/) | Manage student records with input validation |
| [GuessMyNumber](GuessMyNumber/) | Number guessing game that counts your attempts |
| [Quiz](Quiz/) | Console multiple-choice quiz about Java |

## How to run a program

Open a terminal in the program's folder, then compile and run it. For example, for ContactBook:

```bash
cd ContactBook
javac ContactBook.java
java ContactBook
```

Requires JDK 8 or higher.

## Concepts covered

OOP and encapsulation, collections, exception handling, file I/O, input validation.
